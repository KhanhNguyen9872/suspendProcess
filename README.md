## 🌟 Introduction

**SuspendProcess** is a simple Python utility to suspend and resume processes on Windows. It uses the `psutil` library to pause a process and its children, which can be useful for debugging or temporarily freeing up system resources.

## 🚀 Getting Started

### Prerequisites

-   Python 3.x
-   `psutil`, `pywin32`

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/KhanhNguyen9872/suspendProcess.git
    cd suspendProcess
    ```

2.  **Install dependencies**:
    ```bash
    pip install psutil pywin32
    ```

### Usage

1.  **Run the script**:
    ```bash
    python main.py
    ```
